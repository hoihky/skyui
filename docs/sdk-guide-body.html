SkyUI

A cross-platform UI library for .NET built on Avalonia 12. SkyUI combines a semantic design system, a broad essentials catalog, and optional data and diagram modules for line-of-business and productivity applications.

  • Avalonia 12.1.x
  • .NET 10
  • Dark / Light / HC
  • xmlns skyui.dev
  • MIT
GitHub repository ↗ Quick start Architecture Documentation

Disclaimer: This project is an experimental, work-in-progress prototype built with the help of “vibe coding”. Things will break. Features are currently missing, and the build scripts might not work at all. Please be aware that it may not be stable enough for production use now.

Overview

SkyUI is organized into four pillars that mirror how you assemble an application:

Sky Design System Semantic tokens, palettes, typography, icons, spacing, elevation, and WCAG-focused focus rings.
Sky Essentials Forms, navigation, menus, pickers, lists, layout, feedback, and primitives—styled consistently.
Sky Data / Pro Virtual data grid, filter builder, virtual tree, diagram surface, and video timeline.
Sky Platform Desktop-first today; roadmap targets mobile and browser with adaptive layout and touch policies.

The default visual preset is ContentFirstDark: near-black surfaces (#121212–#212121) so content and album-art-style imagery stay primary, with functional accent green (#1ed760) for CTAs and selection—not decoration.

Two ways to consume controls: use typed Sky* controls (SkyCard, SkyDatePicker, …) or style Avalonia primitives with Classes="sky" plus variant classes (sky-primary, sky-outlined).

Quick start

1. Reference packages

Typical app references: SkyUI, SkyUI.Themes.Sky, and optionally SkyUI.Data / SkyUI.Diagram.

2. Include the theme

<Application xmlns="https://github.com/avaloniaui"
             xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
             xmlns:sky="https://skyui.dev"
             x:Class="MyApp.App"
             RequestedThemeVariant="Dark"
             sky:SkyThemeProperties.AccentOverride="#1ED760">

  <Application.Styles>
    <FluentTheme />
    <StyleInclude Source="avares://SkyUI.Themes.Sky/Themes/SkyTheme.axaml" />
  </Application.Styles>
</Application>

3. Use a control

<sky:SkyCard Header="Settings" IsHoverable="True">
  <Button Classes="sky sky-primary" Content="Save" />
</sky:SkyCard>

4. Run the demo gallery

dotnet build SkyUI.slnx
dotnet run --project src/SkyUI.Demo

Theme loading pipeline

Styles are merged in a fixed order so palette colors resolve before semantic brushes and control templates.

SkyTheme.axaml └─ ContentFirstDark.axaml ├─ SkyResources.Themed.axaml (palette per RequestedThemeVariant) ├─ SkyDark/Controls/*.axaml (ControlTheme templates) ├─ SkyDark/Controls/*.Styles.axaml (interaction selectors) ├─ SkyPreset.Primitives.axaml (Button.sky, TextBox.sky, ListBox…) ├─ SkyPreset.Focus.axaml (:focus-visible rings) ├─ SkyIconStyles.axaml └─ SkyTypographyStyles.axaml Token layering: SkyPalette.{Dark|Light|HighContrast}.axaml → palette slots SkyTokens.axaml + SkyDensityTokens.axaml → semantic brushes & metrics SkyLegacyBrushAliases.axaml → Spotify* backward-compat keys

Runtime options (C#)

using SkyUI.Themes.Sky;
using SkyUI.Core.Theming;

SkyTheme.Apply(application, new SkyThemeOptions
{
    AccentColor = Color.Parse("#1ED760"),
    Density = SkyDensity.Compact
});

// Swap palette variant
application.RequestedThemeVariant = ThemeVariant.Light;
application.RequestedThemeVariant = SkyThemeVariants.HighContrast;

Styles must still be included in XAML; SkyTheme.Apply only updates accent brushes and density tokens on the application resource host.

Control implementation patterns

Typed Sky controls

Subclass Avalonia primitives or implement TemplatedControl. Constructor adds sky theme classes. Matching ControlTheme lives under src/SkyUI.Themes.Sky/Themes/SkyDark/Controls/.

  • Thin wrapper — e.g. SkyMenuFlyout adds FlyoutPresenterClasses.Add("sky")
  • Templated — e.g. SkyFormField, SkyCard with PART_* template parts
  • Pseudo-classes — e.g. SkyFormField:error, SkyDivider:horizontal

Styled primitives

Standard Avalonia controls with Classes="sky". Variants defined in SkyPreset.Primitives.axaml. No custom C# type required.

<Button Classes="sky sky-primary" Content="Play" />
<TextBox Classes="sky sky-search" PlaceholderText="Search…" />
<ListBox Classes="sky-nav" />

Density & focus

Density

SkyDensity.Comfortable (default) vs SkyDensity.Compact adjusts button padding, field min-height, and list item metrics via SkyDensityTokens.axaml.

<Application sky:SkyThemeProperties.Density="Compact" ...>

SkyThemeProperties.SetDensity(app, SkyDensity.Compact);

Focus rings

SkyPreset.Focus.axaml applies :focus-visible borders to buttons, inputs, list items, menus, pickers, and expanders—using SkyFocusRingBrush and 2px thickness for WCAG 2.4.7.

Programming guide — theme setup

Minimal application

// App.axaml.cs
public override void OnFrameworkInitializationCompleted()
{
    if (ApplicationLifetime is IClassicDesktopStyleApplicationLifetime desktop)
    {
        SkyTheme.Apply(this, new SkyThemeOptions
        {
            AccentColor = SkyThemeProperties.GetAccentOverride(this),
            Density = SkyThemeProperties.GetDensity(this)
        });
        desktop.MainWindow = new MainWindow();
    }
    base.OnFrameworkInitializationCompleted();
}

Fonts

// Program.cs or AppBuilder
AppBuilder.Configure<App>()
    .UsePlatformDetect()
    .ConfigureSkyFonts();  // SkyUI.Fonts.SkyFonts.Configure

Accent override

SkyThemeProperties.SetAccentOverride(app, Color.Parse("#7C3AED"));
SkyThemeProperties.SetAccentOverride(app, null); // restore palette accent

MVVM patterns

Demos use compiled bindings with x:DataType on the root control and view models in SkyUI.Demo.ViewModels.

  • Forms — bind Validator and ErrorMessage on SkyFormField; commands trigger Validate()
  • Menus — expose KeyGesture properties bound to MenuItem.InputGesture
  • Lists — implement ICheckedListBoxItem or use adapters for tree data
  • Layout — call SkyGridBreakpoint.ResolveColumns on SizeChanged
  • Primitives — bind SkyButtonProperties.IsLoading to async command state
<UserControl x:DataType="vm:FormsDemoViewModel">
  <sky:SkyFormField Label="Email"
                    ErrorMessage="{Binding EmailError}"
                    Validator="{Binding EmailValidator}">
    <TextBox Classes="sky" Text="{Binding Email}" />
  </sky:SkyFormField>
</UserControl>

Validation

// ViewModel
EmailValidator = new CompositeSkyValidator(
    SkyValidators.Required("Email is required."),
    SkyValidators.Email());

// Or inline
field.Validate();  // uses SkyFormField.Validator
field.ClearValidation();

Built-in rules: Required, Email, MinLength, MaxLength, Regex, Range. Combine with CompositeSkyValidator for ordered evaluation.
