## Vision (summary)

**SkyUI** is an Avalonia control suite with:

1. **Sky Design System** — semantic tokens, themes (dark/light/high contrast), icons, adaptive layout.
2. **Sky Essentials** — broad catalog of styled controls and shells for line-of-business apps.
3. **Sky Data / Pro** — virtual grid, filter builder, tree checklist, diagram, and media timeline (existing differentiators).
4. **Sky Platform** — validated desktop, mobile, and browser targets with touch and safe-area policies.

See [development-roadmap.md](./development-roadmap.md) for phases and timelines.
